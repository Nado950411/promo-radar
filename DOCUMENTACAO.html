Visão Geral do Projeto
💡

PromoRadar é um aplicativo mobile-first de promoções de mercados e farmácias. O objetivo é transformar a experiência de compras em algo inteligente, personalizado e econômico, usando IA mockada, gamificação e dados colaborativos.

🚀
Objetivo do App
Proposta de valor principal
  • ✓ Alertar sobre promoções próximas ao usuário
  • ✓ Comparar preços entre lojas automaticamente
  • ✓ Aprender hábitos de compra com IA
  • ✓ Otimizar lista de compras por custo
  • ✓ Oferecer cashback e cupons exclusivos
  • ✓ Criar comunidade colaborativa de promoções
📅
Versões do Projeto
Evolução do desenvolvimento
  • v1 Home + Busca + Filtros básicos
  • v1 Tela de Favoritos e Alertas
  • v1 Histórico de preço + Comparação entre lojas
  • v1 Dark mode + Bottom navigation
  • v2 IA de Recomendações na Home
  • v2 6 novas telas completas
  • v2 Cashback, OCR, Chat IA, Gamificação
✅

Status atual: MVP completo com dados mockados. Pronto para integração futura com Supabase + PostgreSQL, APIs de preços reais e notificações push.

🌙
Dark Mode — Como funciona
ThemeContext.tsx + globals.css
  • 1 ThemeContext lê a preferência do sistema com window.matchMedia('prefers-color-scheme: dark')
  • 2 Salva a preferência em localStorage para persistir entre sessões
  • 3 Adiciona ou remove a classe .dark no elemento <html>
  • 4 globals.css define @variant dark que aplica estilos em todos os filhos de .dark
  • 5 Componentes usam classes como dark:bg-slate-800 e dark:text-white
🛠️
Função cn() — Classes condicionais
src/lib/utils.ts
/* Combina clsx + twMerge para classes Tailwind */ export function cn(...inputs: ClassValue[]) { return twMerge(clsx(inputs)); } /* Uso: aplica classe só se condição for verdadeira */ className={cn( 'px-4 py-2 rounded-xl text-sm', isActive && 'bg-violet-600 text-white', !isActive && 'bg-slate-100 text-slate-600' )}
